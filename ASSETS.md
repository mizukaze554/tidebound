# TIDEBOUND assets and visual limits

## Bundled owner assets

- `public/assets/audio/kulakovka-action-game-620581.mp3` is the exact supplied exploration track. Its SHA-256 is `5e97f15be2d33fb8bc498c52bfeaf716b9a56562cfc932b4b76e92ca30ebf2cf`. The changed filename and PWA cache version make existing installs fetch it again. Music plays only during active gameplay.
- `public/assets/models/wayfarer-male.glb` and `wayfarer-female.glb` are optimized copies of the owner's supplied `boy.glb` and `girl.glb`. Both load through Three.js GLTFLoader with Meshopt decoding. Their mesh and texture budgets were reduced from about 20–21 MB and 1.9 million triangles each to about 2.2–2.4 MB and 190–197 thousand triangles each. The models have no rig or animation clips; gameplay uses body bob and lean for now. The built-in mesh remains a loading and error fallback.
- `public/assets/characters/wayfarer-*.png` are owner supplied portraits. The PWA icons derive from owner supplied title art. Other music loops are generated by `tools/generate_music.py`.

The project owner should confirm publishing rights for supplied media. The repository's MIT software license does not automatically cover those files.

## Optional environment models

The Azure Valley currently uses procedural trees, rocks, ruins, water, and vegetation. These are intentionally shaped 3D placeholders, not finished painted artwork. A lazy model registry can replace its ancient tree and first four forest trees when local assets are available. Put Y-up GLB files under `public/assets/models/environment/` and add paths to `manifest.json`, for example:

```json
{
  "ancientTree": "./assets/models/environment/ancient-tree.glb",
  "broadleaf": "./assets/models/environment/broadleaf.glb",
  "pine": "./assets/models/environment/pine.glb",
  "blossom": "./assets/models/environment/blossom.glb"
}
```

The registry caches source models, reports per-file download progress, reuses their geometry and materials, and retains the procedural fallback when a file is missing. Optional environment art is not precached. For offline use, load the region once while online.

Suitable packs to download manually include the [Quaternius Stylized Nature Mega Kit](https://quaternius.com/packs/stylizednaturemegakit.html) and [Kenney Nature Kit](https://kenney.nl/assets/nature-kit). Check the license on the exact download page before redistribution. No models from either pack are bundled here.

## Current visual limits

The river is a terrain-following animated strip with simple foam, and the waterfall is stylized ribbons. There are no screen-space reflections or full hydrology simulation. Mountains and caves remain procedural silhouettes; caves are not enterable. The distant world uses lower object detail than the starting valley. Runtime measurement in headless software-rendered Chrome is not a substitute for a real phone GPU test.
